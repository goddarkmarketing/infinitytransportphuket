# รถตู้ภูเก็ตกับคาร์ซีทเด็ก ต้องแจ้งอะไรบ้าง

ทริปครอบครัวที่จอง **รถตู้ภูเก็ต** แล้วนึกถึงคาร์ซีทตอนขึ้นรถ มักทำให้ต้องรอหรือเปลี่ยนแผน เบาะเด็กใช้ที่นั่งและพื้นที่ และต้องจัดให้ตรงกับอายุหรือน้ำหนักของเด็ก

บทความนี้บอกว่าควรส่งข้อมูลอะไรตอนจอง ไม่ใช่คู่มือกฎหมายคาร์ซีทฉบับเต็ม และไม่การันตีว่ารุ่นรถทุกคันมีอุปกรณ์ครบโดยไม่ต้องบอกล่วงหน้า ภาพรวมทริปครอบครัวอยู่ที่ [รถตู้ภูเก็ตสำหรับครอบครัว](./article-phuket-van-family-travel.html#family-travel-intro)

> **คำตอบสั้น:** ถ้ามีเด็กเล็ก ให้แจ้งอายุหรือน้ำหนักโดยประมาณ จำนวนคาร์ซีทหรือบูสเตอร์ที่ต้องการ พร้อมจำนวนผู้ใหญ่และกระเป๋า ตอนจอง **รถตู้ภูเก็ต** ไม่รอถึงวันเดินทาง

## ทำไมต้องบอกล่วงหน้า

คาร์ซีทไม่ใช่ของที่ติดมากับทุกงานโดยอัตโนมัติ ทีมงานต้องรู้จำนวนและความต้องการเพื่อจัดรถและอุปกรณ์ให้ตรงงาน

การบอกวันก่อนช่วยให้ยืนยันได้ว่ามีอุปกรณ์พอ และเลือกรุ่นรถที่ติดตั้งได้สะดวก ไม่ใช่แค่มีที่นั่งว่าง

ภาพรวมบริการอยู่ที่ [คู่มือรถตู้ภูเก็ต](./article-phuket-van.html#phuket-van-intro)

<a id="section-2"></a>

## ข้อมูลเด็กที่ควรส่ง

ส่งเป็นชุดเดียวกับงานจอง

- จำนวนเด็กและอายุโดยประมาณ หรือน้ำหนักถ้าทราบ
- ต้องการคาร์ซีทแบบหันหลัง หันหน้า หรือบูสเตอร์
- มีคาร์ซีทนำมาเองหรือต้องการให้จัดให้
- จำนวนผู้ใหญ่ที่นั่งพร้อมกัน
- จุดรับ–ส่ง และเวลาโดยประมาณ

อย่าส่งแค่มีเด็ก โดยไม่บอกช่วงอายุ เพราะอุปกรณ์ไม่เหมือนกันทุกช่วง

<a id="section-3"></a>

## คาร์ซีท บูสเตอร์ หรือนั่งปกติ

| สถานการณ์ทั่วไป | สิ่งที่มักคุยกับทีมงาน |
|---|---|
| ทารกหรือเด็กเล็กมาก | คาร์ซีทที่เหมาะกับช่วงอายุ/น้ำหนัก |
| เด็กโตขึ้นแต่ยังต้องการเสริม | บูสเตอร์ตามที่ตกลง |
| เด็กโตและผู้ปกครองประเมินว่าไม่ต้องใช้ | ยืนยันกับทีมงานให้ชัดว่าไม่ต้องจัดอุปกรณ์ |
| มีคาร์ซีทติดเครื่องบินมาเอง | บอกขนาดและว่าต้องการให้ช่วยติดตั้งในรถหรือไม่ |

บทความนี้ไม่กำหนดอายุตัดขาดเอง ให้ใช้ข้อมูลจริงของลูกแล้วให้ทีมงานยืนยันอุปกรณ์ที่มีในวันนั้น

<a id="section-4"></a>

## ผลต่อจำนวนที่นั่งและกระเป๋า

คาร์ซีทใช้ที่นั่งหนึ่งตำแหน่ง และรถเข็นเด็กกินพื้นที่ท้าย ครอบครัว 2 ผู้ใหญ่ 2 เด็กพร้อมกระเป๋าใบใหญ่ อาจต้องดูรถตู้ขนาดกลางขึ้นไป ไม่ใช่รถเล็กที่โฆษณาที่นั่งพอดีตัวเลขคน

อ่านเรื่องสัมภาระต่อที่ [รถตู้ภูเก็ตสัมภาระกี่ใบ](./article-phuket-van-luggage-guide.html#luggage-guide-intro)

## วันรับส่งสนามบินกับเด็กเล็ก

ขาเข้าสนามบินให้มีเลขไฟลท์ จุดส่งโรงแรม และจำนวนคาร์ซีทในข้อความเดียวกัน คนขับจะได้เตรียมติดตั้งก่อนถึง

ถ้าไฟลท์เลื่อน แจ้งเวลาใหม่พร้อมยืนยันว่ายังต้องใช้คาร์ซีทชุดเดิม อ่านจุดรับสนามบินเพิ่มที่ [คู่มือรับส่งสนามบิน](./article-phuket-airport-van-guide.html#airport-van-guide-intro)

## คำถามที่พบบ่อย

### 1. ทุกงานมีคาร์ซีทแถมไหม

ไม่ควรถือว่าแถมอัตโนมัติ ต้องแจ้งความต้องการและให้ทีมงานยืนยันก่อน

### 2. มีค่าใช้จ่ายเพิ่มสำหรับคาร์ซีทหรือไม่

ขึ้นกับงานและอุปกรณ์ในวันนั้น ไม่มีเรตตายตัวในบทความนี้ ให้ถามตอนขอราคา

### 3. เอาคาร์ซีทจากบ้านหรือเครื่องบินมาเองได้ไหม

ได้ถ้าบอกขนาดและจำนวนล่วงหน้า จะได้จัดที่นั่งและช่วยติดตั้งได้ถูก

### 4. เด็กสองคนต้องใช้คาร์ซีทสองตัวไหม

โดยทั่วไปใช่ ถ้าทั้งคู่ยังต้องการที่นั่งเด็ก แจ้งจำนวนให้ตรง

### 5. บูสเตอร์กับคาร์ซีทต่างกันอย่างไรในแง่การจอง

ต่างอุปกรณ์และช่วงการใช้งาน บอกอายุหรือน้ำหนักแล้วให้ทีมงานแนะนำชนิดที่มี

### 6. จองคาร์ซีทวันเดินทางทันไหม

เสี่ยงไม่ทันโดยเฉพาะช่วงไฟลท์ดึกหรือไฮซีซัน ควรจองพร้อมงานรถ
